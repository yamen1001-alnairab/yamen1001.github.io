# النيرب لتنظيف المباني | Al Nairab Building Cleaning

الموقع الرسمي لشركة النيرب لتنظيف المباني — أبوظبي، الإمارات.

## النشر على GitHub Pages

تم رفع الموقع وسيعمل مباشرة على GitHub Pages. لتوصيل نطاق مخصص:

1. ادخل على **Settings** > **Pages**
2. في خانة **Custom domain** اكتب اسم النطاق (مثال: `alnairab.ae`)
3. اضغط **Save**
4. اذهب إلى Hostinger > إدارة DNS وأضف السجلات التي يظهرها GitHub

## التحديثات

لتحديث الموقع، ارفع الملفات الجديدة مباشرة على GitHub أو اسحبها إلى المتصفح في صفحة الـ repository.
